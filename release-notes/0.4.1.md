# OZ - Stargate 0.4.1

- Fix Discovery with `network.enabled=false`: after the seven-chevron dial, a successful local attempt can now create its gate and DHD. The existing success chance, candidate search and cooldown still apply.
- The hosted relay now accepts servers without a fixed IP allowlist. Network assignment remains automatic through the computed network code or an administrator's override; the code is routing metadata, not authentication. An unpredictable override can isolate a server group.

Requires **OZ Tools 0.26.2** and Rising World Unity with PluginAPI 0.9.3.2. Cross-server travel and shared address books use **OZ Stargate Network 0.4.1**; protocol v1 and existing data remain compatible with 0.4.0. Back up world, native player and plugin databases before updating. Finish active transfers before rolling back either component. Network travel remains off by default.

The offline Discovery fix was built and loaded on Development; its local success path still needs a player test. The accepted placement limitations from 0.4.0 remain: a first arrival can cause fall damage and a new DHD can sit slightly in the ground. Check newly created sites before regular use.
