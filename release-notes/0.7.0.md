# OZ - Stargate 0.7.0

- The Milky Way gate, DHD and wormhole now use the accepted AssetBundle visuals by default on new installations. The gate has animated Chevron and ring parts, and the DHD and Kawoosh keep their tested lighting and motion.
- Administrators can choose **Plattformen** in the radial menu and place a gate on a circular, curved Milky Way, curved Pegasus or Grace of God platform at the aimed floor point. The platforms have walkable collision, near and distant detail levels, and aligned arrival positions.
- Grace of God has subtle lights in its four corner bollards. The platform meshes retain the original near-view detail; the distant detail levels reduce rendering cost.
- Existing gates and world data remain in place. A saved `gate.assetMode=obj` setting continues to select the former OBJ renderer; set it to `bundle` to use the new visuals on an existing installation. If a gate/DHD/wormhole bundle cannot load, the plugin falls back to the former renderer. Back up the Stargate world database before upgrading; older plugin versions cannot write the new platform column without a database rollback.

Requires **OZ Tools 0.26.2**, Rising World Unity with PluginAPI 0.9.3.2, and **OZ Stargate Network 0.5.1** for network features. The relay protocol and Production deployment are unchanged. Finish active transfers before upgrading or rolling back.
