# OZ Stargate 0.9.1

- Stargate discovery searches the centre and four quadrants of each free sector. If those areas yield no suitable sites within range, it continues with other chunks in random order. Search progress survives a server reload.
- The DHD shows when no discovery targets are available and re-enables discovery when a site is found. An empty pool never starts a discovery cooldown.

Requires OZ Tools 0.29.0, Java 25 and Rising World PluginAPI 0.9.3.2. Existing gates and world settings are retained.
