# OZ - Stargate 0.5.1

- Fix Discovery at gates whose site pool is empty: they can now use suitable free sites already found by other gates in their search radius.
- After a new gate is found, remaining gates replenish their pools. Previously unsuitable free sectors are checked again later, while occupied sectors are skipped.

The configured Discovery success chance and cooldown still apply. A free sector must also have suitable terrain and space for a gate and DHD.

Requires **OZ Tools 0.26.2**, Rising World Unity with PluginAPI 0.9.3.2, and **OZ Stargate Network 0.5.0** for network features. No relay update or database migration is required. Preserve world settings and SQLite data when upgrading; back up the plugin and player databases, and complete active transfers before replacing or rolling back the plugin. The patch code was loaded on Development in a 0.5.0 test build; the 0.5.1 package passed automated tests. A successful Discovery attempt with a previously empty pool has not been verified by a player.
