# OZ Stargate 0.8.3

- Prevent a server-side `ConcurrentModificationException` during player spawn from suspending Stargate model rendering for the whole plugin.
- Gate models are created outside the cache update, and an existing model is retained if another callback registered it first.

This fixes the server-side failure identified in the November 9–12 logs. The brief visibility report at 16:16 on November 12 could not be attributed to this exception without that player's client log. Existing gate, player, and world data remain in place. Requires Java 25 and Rising World PluginAPI 0.9.3.2.
