# OZ Stargate 0.8.1

- Server logs now include the full exception stack trace if Stargate model rendering is suspended. This helps diagnose a recurring missing gate.
- This diagnostic update does not change gate rendering or placement behavior. A client `rp` restored visibility in the observed incident; the underlying exception remains to be identified.

Existing gate, player, and world data remain in place. Requires Java 25 and Rising World PluginAPI 0.9.3.2.
