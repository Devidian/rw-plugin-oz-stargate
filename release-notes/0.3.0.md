# OZ - Stargate 0.3.0

Gate audio and timed incoming activation are ready for administrators to configure.

- The plugin includes a **silent** sound theme. Place your own Ogg Vorbis files in `Plugins/OZStargate/audio/<theme>/` and select the folder in administrator PluginSettings. The package contains no series or privately supplied recordings.
- Stargate sounds are on by default. Players can switch them off individually; administrators can adjust the volume from 0 to 100% (default 70%).
- DHD lights, ring rotation, chevrons, opening, open loop, passage, failed dial and shutdown follow gate state. The destination plays the passage sound for arriving players and nearby listeners.
- The source gate opens visually when the target accepts. Seven incoming chevrons light at 400 ms intervals; travel becomes available after 2.8 seconds. A local target is checked at the seventh outgoing lock, and an incoming dial interrupts unfinished outgoing dialing there.
- Travelers are hidden during local transport and while cross-server inventory and clothing are cleared. Successful arrivals become visible after restoration; a failed outgoing transfer restores the player's prior visibility.
- The test-only SQLite JDBC dependency has been updated to `3.53.4.0`.

Requires **OZ Tools 0.26.2** and Rising World Unity with PluginAPI 0.9.3.2. Cross-server travel requires **OZ Stargate Network 0.3.0** and `network.enabled=true` on participating servers; it remains off by default. Upgrade the relay before the plugin, with no active transfers, and preserve world settings and plugin/player databases. The existing manually switched server limitation for nonempty visitor inventories still applies.

The private reference theme used during Development testing is **not** in this repository or release. Administrators are responsible for rights to any themes they add. The hosted test relay is not opened to the public by this release. A travel video awaits PluginAPI support.
