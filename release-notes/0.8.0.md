# OZ Stargate 0.8.0

- The DHD address list shows network gates by default and offers a switch to hide them.
- A native search dialog filters by alias, personal name, local address, or external network address and ID. Empty input clears the search; an active filter highlights the control.
- Filtering, paging, and gate selection use the same visible result list. Search and switch state last only while that DHD view is open.

Existing gate and player data remain in place. Requires Java 25 and Rising World PluginAPI 0.9.3.2.
