# OZ - Stargate 0.6.0

- Give known gates private names and choose the new **Own** address display mode. Faction members can share local gate addresses individually or with **Share all**; membership is checked when the DHD opens.
- The DHD now refreshes its address book for the current network code before showing remote gates. Address rows keep their frame and subtle hover highlight while paging.
- Local gate travel restores the player's original visibility even if the travel-screen completion is missed or the player reconnects.
- When a server changes network code, its own gate addresses move to the new code while other servers' addresses remain with their original code.

Requires **OZ Tools 0.26.2**, Rising World Unity with PluginAPI 0.9.3.2, and **OZ Stargate Network 0.5.1** for network features. Upgrade the relay first. Faction sharing uses the optional OZ Factions integration. Existing gate, world-setting and SQLite data are retained; back up plugin, player and relay databases and finish active transfers before upgrading or rolling back.
