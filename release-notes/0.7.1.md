# OZ - Stargate 0.7.1

- Gate, DHD and event horizon now always use the accepted AssetBundle visuals. The old `gate.assetMode` value in world settings is ignored; no data migration is needed.
- `/sg previewgate` shows the bundle gate prefab at the same feet anchor and depth as a permanent gate, without collision or lights for two minutes, visible only to the administrator.
- The download is smaller because generated OBJ files and build reports are no longer packaged. Source files remain in the repository for bundle reproduction.

Install this plugin alongside OZ Tools 0.26.2 or newer and Stargate Network 0.5.1. Back up world data before upgrading. A missing or unloadable bundle now suspends the affected visual and reports the error in the server log.
