# OZ - Stargate 0.2.0

- Place one gate per sector with a matching DHD. Administrators can create, move and remove both through the radial menu; new gates receive a global address, aligned passage and safe arrival point together.
- Dial local sector destinations or, when enabled by an administrator, gates on trusted remote servers. Use the DHD and walk through an open event horizon to travel.
- See a persistent, colliding Milky Way gate with animated ring, chevrons and wormhole effects, plus a directly usable DHD model.
- Keep inventory and clothing through local and cross-server travel. A target already holding an earlier visitor inventory rejects a new arrival before the source inventory is removed.

Requires **OZ Tools 0.26.2** and Rising World Unity with PluginAPI 0.9.3.2. Cross-server travel requires **OZ Stargate Network 0.2.0** and `network.enabled=true` on participating servers; it is off by default. The relay remains connected for globally unique address reservation. Back up both native player and plugin databases before upgrading or rolling back. Do not mix plugin and relay versions during active transfers.

The relay is for a controlled group of trusted servers. Its network code groups compatible worlds; it does not authenticate servers. The existing hosted relay is not opened to the public by this release. NPC travel and a native importer performance fix are deferred.
