# OZ - Stargate 0.5.0

- Set and change gate aliases from the DHD. Each player can display aliases, local addresses or network addresses; known local addresses remain the fallback.
- Admins can mark start gates with a confirmed DHD switch. Random first arrival remains the default; when disabled, new local visitors arrive at marked start gates, with the gate in sector 0,0 as fallback. Incoming cross-server travelers still use their destination gate.
- Configure the Discovery cooldown and an optional admin exemption. Optional Discord Connect channels can announce internal and external travel, successful discoveries and network status without publishing the network code.
- The DHD controls are spaced more clearly, and repeated interaction with the same gate no longer replaces its open menu.

Requires **OZ Tools 0.26.2** and Rising World Unity with PluginAPI 0.9.3.2. Upgrade to **OZ Stargate Network 0.5.0** before updating this plugin to use synchronized aliases and network addresses. Existing gates, world settings and plugin data are retained; back up the plugin, player and relay databases before upgrading. Cross-server travel remains off by default.
