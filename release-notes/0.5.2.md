# OZ - Stargate 0.5.2

- The DHD can be reopened after closing it with Escape. A stale server-side menu session no longer prevents interaction.
- Administrators can aim at a floor point to place the DHD with `/sg placedhd` or the radial menu. Placement rejects walls, ceilings, and insufficient space above the console.
- The radial menu's combined gate-and-DHD action now points the gate toward the DHD and puts the DHD's back toward the gate. Its arrival point follows the gate's front; separate placements retain their previous orientation.

Requires **OZ Tools 0.26.2**, Rising World Unity with PluginAPI 0.9.3.2, and **OZ Stargate Network 0.5.0** for network features. No relay update or database migration is required. Preserve world settings and SQLite data when upgrading. Back up the plugin and player databases and complete active transfers before replacing or rolling back the plugin. The DHD interaction and placement changes were accepted on a local client; the release package is validated separately by CI.
