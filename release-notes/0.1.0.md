# OZ - Stargate 0.1.0

- List available gates with `/sg gatelist`, dial with `/sg dial <gate>`, and travel with `/sg warp <gate>`.
- Take inventory and worn clothing with you. Cancelled unclaimed travel restores your items; the destination's previous inventory is kept for your ordinary login after returning.
- Administrators register and remove gates; regular players cannot use management or inventory debug commands.

Requires **OZ Tools 0.26.2**, Rising World Unity with PluginAPI 0.9.3.2, and **OZ Stargate Network 0.1.0**. Extract the ZIP into the server Plugins directory and configure a reachable relay and advertised game address.

Operate within a controlled group of trusted game servers. The network code groups compatible worlds; it does not authenticate servers. This release does not open the existing hosted relay to public access. A forced target game-process crash after claim is not covered by native player acceptance.
