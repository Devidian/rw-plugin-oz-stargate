# OZ Stargate 0.8.2

- The DHD now remembers each player's network-gate filter choice. Turning network gates off or on stays in effect after closing the DHD or reconnecting.
- Network gates remain visible by default for players who have not changed the filter.

Existing gate, player, and world data remain in place. Requires Java 25 and Rising World PluginAPI 0.9.3.2.
